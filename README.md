# 顺场

婚礼当天流程调度工具：把当天的时间轴编排成一张调度单，在现场按单执行。核心是「延误发生时，立刻算出新的时间，并让所有人看到同一份」。

## 已实现

- 手册列表、三套内置模板（中式 / 西式 / 年会）、本地存储与复制删除
- 编排台：时间轴实时重算、锁定时刻吸收、60 环节上限、冲突标记
- 发布分发：离线 SVG 二维码、`.json` 文件、六位短码
- 执行台：现场倒计时、完成 / 长按 3 秒跳过、一键顺延与锁定预览
- 跟随视图：只读时间轴、负责人筛选、同步条与过期提醒
- 导出：A4 横版打印视图，超过 40 环节自动分页并重复表头

## 命令

```bash
npm run dev    # 启动开发服务
npm run build  # 生产构建（Web + Lynx 两份 bundle）
npm run test   # 运行测试
```

## 技术

一套 ReactLynx 代码同时产出 Web 与 Lynx 原生 bundle，数据默认只保存在本设备，不依赖账号与网络。Web 端支持文件导入导出与打印；原生端通过二维码展示与六位短码完成分发和同步。
