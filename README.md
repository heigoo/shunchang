# 顺场

婚礼当天流程调度工具：把当天的时间轴编排成一张调度单，在现场按单执行。核心是「延误发生时，立刻算出新的时间，并让所有人对齐到同一版」。

## 已实现

- 手册列表、三套内置模板（中式婚礼 / 西式婚礼 / 年会）、本地存储与复制删除
- 编排台：时间轴实时重算、锁定时刻吸收、60 环节上限、冲突标记
- 发布分发：本地生成 SVG 二维码、`.json` 文件、九位短码（`XXX-XXX-XXX`）
- 执行台：现场倒计时、完成 / 跳过（二次确认）、一键顺延与锁定预览
- 跟随视图：只读时间轴、负责人筛选、同步条与 15 分钟过期提醒
- 导出：A4 横版打印视图，每页 40 个环节并重复表头

## 同步方式

- 跟随页通过二维码或链接载入，载入的是当时的发布/执行快照，只读。
- 执行开始后，执行台提供九位短码；短码仅用于**已持有同一手册**的设备对齐状态，首次加入仍需扫码或导入文件。
- 短码同步不含逐项执行结果，「已完成」按进度推断；距上次同步超过 15 分钟标记为过期。
- 没有服务器推送或自动同步：每次对齐都由扫码、复制链接、输入短码或导入文件触发。
- 旧六位短码已停用，输入后会提示重新扫码；请使用最新二维码、链接或九位短码。

## 命令

```bash
npm run dev    # 启动开发服务
npm run build  # 生产构建（Web + Lynx 两份 bundle）
npm run test   # 运行测试
```

## 技术

一套 ReactLynx 代码同时产出 Web 与 Lynx 原生 bundle。数据只保存在本设备，不依赖账号；跨设备跟随/同步需要打开在线跟随页或通过文件传递。Web 端支持文件导入导出与打印；原生端通过二维码与九位短码分发、对齐状态。

预览说明：LynxExplorer 宿主未提供持久化存储模块，数据仅保留在当前进程内；接入真实宿主提供的 `lynx.getStorage` / `lynx.setStorage` 后即可跨重启保存。
